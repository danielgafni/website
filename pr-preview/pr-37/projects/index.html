Projects¶

Projects I've built professionally

  • dagster-ray

    A library for running Dagster jobs on Ray, so the same pipeline code runs locally or on a remote Ray cluster with fast startup and autoscaling.

    danielgafni/dagster-ray

  • dagster-polars

    An integration library for loading and saving Polars DataFrames in Dagster assets and ops. It began as a standalone project and is now part of the main Dagster repository.

    danielgafni/dagster-polars

  • Talk: building a Feature Store with Dagster and Ray

    A recorded Dagster Community Meetup talk about the feature store built at Sanas, where Dagster orchestrated large-scale model inference on autoscaling KubeRay clusters.

    Watch on YouTube

  • Freak

    A Python package that exposes a program's state, defined as a Pydantic model, over HTTP so long-running jobs like bots or model training can be controlled remotely.

    danielgafni/freak

  • Zakupki.Hack: winning solution

    The first-place solution from the Zakupki.Hack hackathon: a service that recommends public procurements to companies based on their descriptions, deployed on Kubernetes.

  • RaifHack: most loved solution

    A Siamese TabNet model for the RaifHack competition that predicts commercial real estate prices by comparing each property with similar residential ones. It won the most loved solution award.

    danielgafni/RAIFHACK

  • Repalette

    A tool that recolors any image to match a given six-color palette, built on an implementation of the PaletteNet GAN trained on palettes scraped from Design Seeds.

    danielgafni/repalette

  • CardioSpike: winning solution

    The winning entry in the CardioSpike competition: a neural network combining convolutions and attention that detects anomalies in heart rhythm time series, delivered with a simple UI.

    gleberof/cardiospike

  • NixOS Config

    Daniel Gafni's NixOS flake, which manages his PC and laptop from one pinned, declarative configuration that GitHub Actions builds and updates automatically.

    danielgafni/nixos
